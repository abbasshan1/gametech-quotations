# GameTech Peshawar — Quotations

Static quotation catalogue for GameTech Peshawar custom gaming PCs and workstations.

## GitHub Pages

Recommended repository name:

`gametech-quotations`

After enabling GitHub Pages from **Settings → Pages → Deploy from a branch → main → / (root)**, the site will be available at:

`https://abbasshan1.github.io/gametech-quotations/`

## Files

- `index.html` — complete self-contained quotation page

No Node.js, database, API, or build process is required.

## Updating quotations

All build data is contained in the `builds` array near the bottom of `index.html`.
